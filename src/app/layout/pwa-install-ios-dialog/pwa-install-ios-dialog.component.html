install_mobile Installer l'application

Pour installer Caribou Audit sur votre iPhone ou iPad, suivez ces étapes dans Safari :

  1. 1 Touchez le bouton Partager ios_share en bas de l'écran.
  2. 2 Faites défiler et choisissez « Sur l'écran d'accueil » add_box.
  3. 3 Touchez Ajouter en haut à droite.

info Cette fonction n'est disponible que dans Safari sur iOS.
